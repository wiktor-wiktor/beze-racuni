This will be a simple, locally served website aiming to share payments for apartment invoices.

1. It should have two sides - password-locked admin (for me) and a public presentational one for all of of us sharing the payments.
2. The admin side should allow to simply add new recipients and manage the existing ones. The recipient entry should consist of their name and a share for every existing payment
3. The admin side should allow for adding invoices for the (by default) current month, by inputing the amount and picking the type. No pictures attached for now.
4. The public facing side should be in the form of a "feed" presenting each added invoice to everyone.
5. When there is a complete set of the invoices turned in by the admin there are notifications (as posts) published on the feed showing for everyone involved of how much they owe
